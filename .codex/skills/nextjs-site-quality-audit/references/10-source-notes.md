# 10 — Source Notes

Use these as source anchors when maintaining the skill.

## OpenAI Codex Skills

- A skill is a directory with `SKILL.md` plus optional `references/`, `scripts/`, and `assets/`.
- `SKILL.md` requires frontmatter with `name` and `description`.
- Codex uses progressive disclosure: metadata first, full skill instructions only when selected, references/scripts only when needed.

Primary docs:

- https://developers.openai.com/codex/skills
- https://developers.openai.com/codex/use-cases/reusable-codex-skills
- https://developers.openai.com/codex/concepts/customization
